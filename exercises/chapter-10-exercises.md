# Övningar till kapitel 10: När juridiken stoppar, styr eller öppnar väg

## Syfte

Övningarna hjälper dig att skilja mellan juridiska hinder, villkor, osäkerheter och handlingsutrymme. Målet är att juridiska svar ska bli lättare att omsätta i arbete.

## Övning 1: Sortera svarstypen

Klassificera varje svar som:

- stoppar,
- styr,
- öppnar väg,
- kräver mer underlag,
- kräver beslut om kvarstående risk.

### Svar

1. ”Teamet bör inte bygga funktionen på detta sätt eftersom ansvarsfördelningen blir otydlig.”
2. ”Det kan vara möjligt om åtkomst begränsas till handläggare i rätt ärendeslag.”
3. ”Vi kan inte bedöma frågan förrän ni har beskrivit vilka uppgifter som används.”
4. ”Syftet kan sannolikt uppnås genom ett beslutsstöd i stället för automatisk prioritering.”
5. ”Det finns en risk som inte kan elimineras helt och som bör beslutas av rätt ansvarsnivå.”
6. ”Den föreslagna lösningen bör inte införas utan omdesign.”

### Reflektion

- Vilka svar kräver direkt juristmedverkan?
- Vilka svar kan teamet omsätta i arbete?
- Vilka svar behöver dokumenteras i beslutsnotering?

## Övning 2: Gör stoppet konstruktivt

Utgå från formuleringen:

> Juridiken säger nej till lösningen.

Skriv om svaret så att det innehåller:

1. vad stoppet gäller,
2. vad stoppet inte gäller,
3. varför vägen inte bör fortsätta,
4. vilket underlag bedömningen bygger på,
5. vilka alternativa vägar som kan undersökas,
6. när frågan kan prövas igen.

## Övning 3: Villkor blir arbete

Välj ett juridiskt villkor och översätt det till konkreta arbetsuppgifter.

Exempel på villkor:

- ”Åtkomsten måste begränsas.”
- ”Användaren behöver få tydligare information.”
- ”Handläggarens ansvar behöver framgå.”
- ”Beslutet behöver kunna följas upp i efterhand.”
- ”Konsekvensbedömningen behöver uppdateras före utrullning.”

Skapa minst tre arbetsuppgifter per villkor.

## Övning 4: Skriv ett juridiskt svarskort

Använd mallen:

```text
Fråga:

Kort bedömning:

Villkor eller hinder:

Handlingsalternativ:

Ansvar:

```

Välj en fråga från din egen organisation eller använd följande case:

> Ett team vill använda uppgifter från ett befintligt ärendesystem för att automatiskt prioritera inkommande ärenden i en ny digital tjänst.
