# Övningar till kapitel 14: Att bygga organisatorisk juridisk förmåga

## Övning A: Mognadsbedömning

Placera organisationen på en av nivåerna.

| Nivå | Kännetecken | Stämmer hos oss? | Exempel |
|---|---|---|---|
| 1. Reaktiv juridik | Juristen kopplas in sent och oregelbundet | | |
| 2. Strukturerad juridisk avstämning | Det finns vissa forum, mallar och ingångar | | |
| 3. Skalbar juridik i flödet | Juridiska signaler fångas och triageras löpande | | |
| 4. Lärande juridisk förmåga | Juridiska mönster återförs till styrning, vägledning och arbetssätt | | |

Avsluta med att formulera ett bevis för vald nivå och ett hinder för nästa nivå.

## Övning B: Personberoendekarta

| Fråga | Svar |

Identifiera två sätt att minska personberoendet utan att sänka juridisk kvalitet.

## Övning C: Återföring från en juridisk fråga

Välj en juridisk fråga som nyligen hanterats.

Besvara:

1. Var i arbetet uppstod frågan?
2. Vem upptäckte den?
3. När kopplades juristen in?
4. Vilka antaganden byggde bedömningen på?
5. Blev beslutet dokumenterat?
6. Har frågan återkommit tidigare?
7. Vad bör organisationen lära av frågan?

Placera återföringen på rätt nivå:

| Återföringsnivå | Markera | Möjlig åtgärd |
|---|---|---|
| Lokal återföring | | Uppdatera backlogg, beslutsnotering eller konsekvensbedömning |
| Gemensam återföring | | Skapa riskkort, vägledning eller utbildning |
| Styrande återföring | | Ändra princip, forum, prioritering eller beslutsregel |

## Fördjupning: Juridisk förmågekarta

Skapa en karta över hur juridiska frågor ska röra sig genom organisationen.

Ta med:

- upptäckt av juridiska signaler,
- juridisk intake,
- triagering,
- juridiska forum,
- beslutsnoteringar,
- konsekvensbedömning,
- eskalering till ledning,
- återföring till vägledning, riskkort och styrning.

Markera med en symbol var flaskhalsar, personberoende och otydliga ansvar finns.
