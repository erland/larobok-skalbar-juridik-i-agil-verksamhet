# Skalbar juridik i agila arbetssätt

**En praktisk handbok för jurister, arkitekter, kravfångare och verksamhetsspecialister**

Detta är ett bokprojekt skapat med Lärobokskaparen.

## Projektstatus
- Titel: Skalbar juridik i agila arbetssätt
- Författare: Erland Lindmark
- Språk: Svenska
- Version: 0.1
- Fas: Kapitelgenerering komplett; redo för granskning och eventuell exportförberedelse

## Struktur
- `docs/` innehåller bokspecifikation, kapitelplan, canon, terminologi, status och exportmetadata.
- `chapters/` innehåller inledning och kapitel.
- `exercises/` innehåller separata övningsfiler vid behov.
- `examples/` innehåller scenarier och icke-kodexempel.
- `assets/` innehåller omslag, bildpromptar och eventuella framtida bilder.
- `exports/` är avsedd för genererade EPUB/PDF/DOCX/Markdown-filer.

## Nästa steg
1. Granska kapitel 14 i `chapters/14-organisatorisk-juridisk-formaga.md`.
2. Granska övningarna i `exercises/chapter-14-exercises.md`.
3. Genomför helhetsgranskning av progression, terminologi och exempel.
4. Därefter kan projektet förberedas för EPUB/PDF/DOCX-export.
